# ergonoi design contract

Draft 0.1, 28 November 2026. Open `index.html` in a browser; it needs no server and no network.

- `index.html`: the contract (rules, specimens, current deviations, open decisions)
- `tokens.css`: all values (colours, type, space, lines, sizes); the single source for the apps
- `components.css`: reference implementation of the controls and surfaces, built from the tokens
- `contract.css`: layout of the contract page itself
- `fonts/`: the self-hosted fonts with their licences (SIL OFL)
- `img/`, `shots/`: screenshots of Agenda 0.9.34 (desktop 1440 × 900, phone 390 × 844)
