    New facets and topics
    • A value entered in this field is kept: the app writes a line Tag definition: … #type-meta for it. You can add a description to that line in the Text view.
    • With several journals, the app asks which journal a new facet belongs to (entries with it are written there), and in which journals a new topic is kept.
    • Values that only appear in typed or imported text have no such line; they disappear 90 days after the last entry carrying them is closed.
    • To remove a facet: the journal's dialog, Remove a facet from this journal; its entries get another facet first. A topic: give its entries another value (Settings → Rename tag; if the other value exists, both are merged) or close them, and delete its Tag definition line in the Text view. A tag of one entry: the − next to its +.
    • A facet declared by a shared journal belongs to that journal: entries with it are written there, and it is renamed or removed there.
