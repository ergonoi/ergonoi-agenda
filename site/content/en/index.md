# ergonoi Agenda

Appointments, tasks and notes in one place, just like in a paper notebook – but rearranged and moved to another day with a simple swipe. On every device, in any browser, readable only by you and by those you share it with.

**ergonoi Agenda is a planning journal that is light enough to understand completely: one encrypted text file per journal, a small server that cannot read it, and an app that runs in the browser.**

---

## One list

Most tools split a day into a calendar, a task manager and a notes app, each with its own account and its own idea of what belongs where. The agenda keeps them together. An appointment, a task and a note are lines in the same journal; they differ by a few tags, not by the program that holds them. What is due today stands in one place.

## Lightweight

An entry is a line of text with tags: `Call the plumber #facet-home #date-2026-11-20`. The journal is a list of such lines. Nothing is hidden in a database, and every line can be read, exported and edited as plain text. The app is a single web page that works offline; the server stores one file per journal and does little else.

## Confidential by design

Every line is encrypted on your device before it is sent. The key comes from eight words that only you hold; the server never sees them and could not read the journal if it wanted to. There is no account with a provider, no e-mail address, no profile.

## Everywhere

The agenda runs in any current browser, on a phone, a tablet or a computer, and can be installed on the home screen like an app. All devices that know the words of a journal show the same journal.

## Sharing on your own terms

A journal can be shared with anyone, whatever device or system they use: you give them a code, and they add the journal to theirs. Some may write, others only read. Nobody needs an account with anyone for it.

## Open

ergonoi Agenda is free software. The code, the file format and the documentation are public, and anyone can run their own server.
