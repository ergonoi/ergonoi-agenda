# Sharing a journal

*Who gets which code, and what it allows.*

## Three levels

A journal of version 2 has three codes. Each gives less than the one before, and none can be derived from a weaker one.

| Code | Form | Allows |
|---|---|---|
| **Words** | eight words | everything: reading, writing, deleting, and the owner's private lines. Keep them to yourself. |
| **Ally code** | sixteen words | reading and writing the entries. For the people who plan with you. |
| **Guest code** | a text beginning with `g1.` | reading only. For those who should see the dates. |

The codes are in the journal's dialog under *Sharing*: *Show phrase*, *Ally code*, *Guest code*, and *Show QR code* to pass a code from screen to camera. A code never travels through the server or a link; you pass it yourself, in person, by message or on paper.

## What the others see

Allies and guests see the entries, the facets and the name of the journal. They do not see your private lines: the words of other journals you hold, your aliases, the facets you added for yourself. These lines are in the same file, but encrypted with a key that only the owner has.

## Who uses it

*Used by* in the journal's dialog tells how many people have used the journal recently: you, and how many others. The server counts by an identifier that is different for every journal and does not tell who someone is. It is a guide, not proof.

## Passing codes on

Whoever holds a code can pass it on: an ally can give the ally code or the guest code to someone else. This cannot be prevented by any technique. If a code has gone too far, *Stop sharing* gives the journal new words and codes (see *Handing over and ending*).

## Sharing without a common platform

The others need no account, no particular phone and no particular calendar. They open the address of the server in any browser, set up their own journal and add yours with the code. Families with different systems, clubs, neighbours: everyone uses the same journal in the same way.
