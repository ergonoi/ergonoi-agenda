# Calendars, printing, export

*Bringing appointments in, and taking them out again.*

## Importing calendar files

*Import entries* → *Choose files* accepts one or several calendar files (`.ics`): invitations you received, or the export of a work or private calendar. In the preview you choose the facet, for all events or one by one. Importing the same file again later updates the entries instead of duplicating them. Repetitions the agenda cannot express are imported once and marked for review.

Plain text can be imported the same way: one entry per line, pasted or from a file. A preview shows what will be added before anything changes.

## Exporting a calendar

*Settings → Export calendar* writes the open entries of the facets you choose, for 30 days, three months or all, into one `.ics` file that other calendar programs can import. This file is not encrypted.

## Printing

*Settings → Print* prints either the coming days as a checklist with room for notes, or the memos. You choose the facets; the facets switched on in the facet bar are preselected.

## The journal file

*Export journal file* in a journal's dialog downloads the encrypted file of the journal. With its words it can be opened in any browser with *Open a local journal file*, without a server. It is also a backup that only you can read.
