# οὐθείς Agenda

Termine, Aufgaben und Notizen in einer Liste. Auf jedem Gerät, in jedem Browser, lesbar nur für dich und für die, mit denen du sie teilst.

**οὐθείς Agenda ist ein Planungsjournal, das leicht genug ist, um es ganz zu verstehen: eine verschlüsselte Textdatei je Journal, ein kleiner Server, der sie nicht lesen kann, und eine App, die im Browser läuft.**

---

## Eine Liste

Die meisten Werkzeuge verteilen einen Tag auf einen Kalender, eine Aufgabenverwaltung und eine Notiz-App, jede mit eigenem Konto und eigener Vorstellung davon, was wohin gehört. Die Agenda hält sie zusammen. Termin, Aufgabe und Notiz sind Zeilen im selben Journal; sie unterscheiden sich durch einige Tags, nicht durch das Programm, das sie verwaltet. Was heute ansteht, steht an einer Stelle.

## Leichtgewichtig

Ein Eintrag ist eine Textzeile mit Tags: `Installateur anrufen #facet-home #date-2026-11-20`. Das Journal ist eine Liste solcher Zeilen. Nichts verschwindet in einer Datenbank; jede Zeile lässt sich als Text lesen, exportieren und bearbeiten. Die App ist eine einzelne Webseite, die auch offline arbeitet; der Server speichert eine Datei je Journal und tut sonst wenig.

## Vertraulich durch die Bauart

Jede Zeile wird auf deinem Gerät verschlüsselt, bevor sie es verlässt. Der Schlüssel entsteht aus acht Wörtern, die nur du kennst; der Server bekommt sie nie zu sehen und könnte das Journal nicht lesen, selbst wenn er wollte. Es gibt kein Konto bei einem Anbieter, keine E-Mail-Adresse, kein Profil.

## Überall erreichbar

Die Agenda läuft in jedem aktuellen Browser, auf Telefon, Tablet und Rechner, und lässt sich wie eine App auf dem Startbildschirm ablegen. Alle Geräte, die die Wörter eines Journals kennen, zeigen dasselbe Journal.

## Teilen nach eigenen Bedingungen

Ein Journal lässt sich mit jedem teilen, gleich welches Gerät oder System er verwendet: Du gibst einen Code weiter, und die anderen nehmen das Journal in ihre Agenda auf. Manche dürfen schreiben, andere nur lesen. Niemand braucht dafür ein Konto bei irgendwem.

## Offen

οὐθείς Agenda ist freie Software. Code, Dateiformat und Dokumentation sind öffentlich, und jeder kann einen eigenen Server betreiben.
