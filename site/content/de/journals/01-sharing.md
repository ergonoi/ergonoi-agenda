# Ein Journal teilen

*Wer welchen Code bekommt, und was er erlaubt.*

## Drei Stufen

Ein Journal der Version 2 hat drei Codes. Jeder gibt weniger als der vorige, und keiner lässt sich aus einem schwächeren ableiten.

| Code | Form | Erlaubt |
|---|---|---|
| **Wörter** | acht Wörter | alles: lesen, schreiben, löschen und die privaten Zeilen des Owners. Behalte sie für dich. |
| **Ally-Code** | sechzehn Wörter | die Einträge lesen und schreiben. Für die, die mit dir planen. |
| **Guest-Code** | ein Text, der mit `g1.` beginnt | nur lesen. Für die, die die Termine sehen sollen. |

Die Codes stehen im Dialog des Journals unter *Sharing*: *Show phrase*, *Ally code*, *Guest code*, und *Show QR code*, um einen Code vom Bildschirm in eine Kamera zu geben. Ein Code wandert nie über den Server oder einen Link; du gibst ihn selbst weiter, persönlich, per Nachricht oder auf Papier.

## Was die anderen sehen

Allies und Guests sehen die Einträge, die Facetten und den Namen des Journals. Deine privaten Zeilen sehen sie nicht: die Wörter anderer Journale, die du hältst, deine Aliase, die Facetten, die du nur für dich ergänzt hast. Diese Zeilen liegen in derselben Datei, aber verschlüsselt mit einem Schlüssel, den nur der Owner hat.

## Wer es verwendet

*Used by* im Dialog des Journals sagt, wie viele Personen das Journal zuletzt verwendet haben: du, und wie viele andere. Der Server zählt anhand einer Kennung, die für jedes Journal eine andere ist und nicht verrät, wer jemand ist. Das ist ein Anhaltspunkt, kein Beweis.

## Codes weitergeben

Wer einen Code hat, kann ihn weitergeben: Ein Ally kann den Ally-Code oder den Guest-Code an jemand anderen geben. Keine Technik kann das verhindern. Ist ein Code zu weit gewandert, gibt *Stop sharing* dem Journal neue Wörter und Codes (siehe *Übergeben und beenden*).

## Teilen ohne gemeinsame Plattform

Die anderen brauchen kein Konto, kein bestimmtes Telefon und keinen bestimmten Kalender. Sie öffnen die Adresse des Servers in irgendeinem Browser, legen ihr eigenes Journal an und fügen deines mit dem Code hinzu. Familien mit verschiedenen Systemen, Vereine, Nachbarn: Alle verwenden dasselbe Journal auf dieselbe Weise.
