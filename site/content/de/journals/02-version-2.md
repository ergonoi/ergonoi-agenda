# Version 2

*Owner, Allies und Guests — und wie man ein älteres Journal umstellt.*

## Was sich geändert hat

In Version 1 waren die acht Wörter der einzige Code: Wer ein Journal teilte, hatte alle Rechte, auch das Löschen. Version 2 trennt die Stufen: Der Owner behält die Wörter, Allies bekommen einen Code zum Lesen und Schreiben, Guests einen zum Lesen. Was die Schlüssel nicht regeln, setzt der Server durch: Nur der Owner kann das Journal löschen oder als Ganzes ersetzen.

Neue Journale haben Version 2. Die Journalliste zeigt für jedes Journal die Version und deine Stufe.

## Ein Journal umstellen

Journale der Version 1, die du angelegt hast, lassen sich umstellen: im Dialog des Journals *Version → Upgrade to version 2*. Die App kopiert das Journal in ein neues der Version 2 mit neuen Wörtern, und du bist sein Owner. Die neuen Wörter werden einmal angezeigt: Schreib sie auf.

- Das alte Journal bleibt auf dem Server und verweist auf das neue. Wer es mit den alten Wörtern öffnet, wird als Guest zum neuen Journal geführt und erfährt das.
- Gib denen, die schreiben sollen, den Ally-Code des neuen Journals.
- Verwendet niemand mehr das alte Journal, entfernt es *Delete the version 1 journal on server*.

Ein Journal, das jemand anderes angelegt hat, kann nur dieser umstellen.

## Dein Default-Journal auf anderen Geräten

Stellst du dein Default-Journal um, verwendet das Gerät, auf dem du es tust, sofort das neue. Deine anderen Geräte bemerken die Umstellung und fragen im Dialog des Default-Journals nach den neuen Wörtern. Bis du sie dort eingibst, kommt trotzdem im neuen Journal an, was sie schreiben.

## Vergessene Wörter

Solange das alte Journal auf dem Server liegt, führen seine alten Wörter noch zum Inhalt: Das Kommandozeilenwerkzeug gibt das alte Journal aus und über dieses das neue als Guest, und die Zeilen lassen sich in ein frisches Journal übernehmen. Ist das alte Journal gelöscht, gibt es diesen Rückweg nicht mehr; bewahre die neuen Wörter sicher auf.
